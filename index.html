Lab guide

Start here (beginners)
    

  • The green screen tells you the next step. The red displays show the address (left) and the data (right).
    • 

  • Numbers are hex (0-9, A-F). Typing 500 means address 0500h.
    • 

  • When the display shows 8086 uP the kit is idle and the black keys are commands: 0 EB, 1 ER, 2 GO, 3 ST, 4 IB, 5 OB, 6 MV, 7 EW, 8 IW, 9 OW, C BC, E VR. While you type an address or a value they are plain digits.
    • 

  • NEXT confirms and moves on, TTY finishes or exits, B.S erases a digit, RESET restarts the kit (memory is kept).
    • 



Your first program
Store B4 AA CC (MOV AH,0AAh then INT 3) at 0500 and run it:
    

  1. At the idle screen press 0 (EB).
    2. 

  2. Type 500, then NEXT.
    3. 

  3. Type B4 NEXT, AA NEXT, CC NEXT.
    4. 

  4. Press TTY to finish.
    5. 

  5. Press 2 (GO), type 500, then press TTY.
    6. 

  6. It stops at CC. AX in the Registers card now shows AA00.
    7. 



Edit memory (EB / EW)
    

  1. 0 (EB) edits bytes, 7 (EW) edits 16-bit words.
    2. 

  2. Type the address (any number of digits), then NEXT.
    3. 

  3. Type a value, then NEXT to store it and move to the next address. PRV stores and goes back one.
    4. 

  4. NEXT with nothing typed just moves on, so you can browse memory.
    5. 

  5. TTY stores what you typed and exits.
    6. 

EW stores the low byte first (1234 is saved as 34 12). RAM is 00000-3FFFF.


Insert and delete bytes (INS / DEL)
    

  1. Open a byte with 0 (EB) or 7 (EW): type the address, then press NEXT to view the data.
    2. 

  2. Note: INS and DEL only work here (in data mode). If pressed during address input, the green screen will guide you.
    3. 

  3. INS opens a 00h gap at that address, shifting subsequent bytes up.
    4. 

  4. DEL removes the current byte, shifting subsequent bytes down.
    5. 

Jump and call offsets are not fixed up automatically, check them after editing.


Fill, move and compare blocks (FILL, MV, BC, VR)
    

  • FILL (the PRV key at idle): SA start address, EA end address, DAtA fill byte. NEXT after the last value runs it.
    • 

  • MV (6): SA source start, EA source end, dESt destination start. Overlapping blocks are copied correctly.
    • 

  • BC (C) and VR (E): SA, EA, then SA2 = start of the second block. On a difference the kit pauses: the address display shows the address in the first block and the data display shows the byte of block 1 followed by the byte of block 2. NEXT looks for the next difference, TTY stops. PASS means the blocks are identical.
    • 

  • While a prompt is open, PRV goes back one prompt and TTY cancels without changing memory. A wrong range shows Err and the status line says why.
    • 



Port I/O (IB, IW, OB, OW)
    

  • IB (4) and IW (8): type the port address (up to 4 hex digits), NEXT. The address display shows the port and the data display shows the value (IW joins the ports n and n+1). NEXT and PRV move to the next or previous port; typing a new address starts over; TTY exits.
    • 

  • OB (5) and OW (9): type the port and NEXT, then type a value and NEXT to write it. You can write more values to the same port; TTY exits.
    • 

  • Ports 00h and 80h are the LEDs D7-D0 (shown on the Assembly editor screen). Every other port keeps the last value written, and IN instructions in your programs read it back.
    • 



Interrupts and function keys (VCT, F1-F3)
    

  • VCT / INTR: type the vector (00-FF), NEXT. The kit pushes FLAGS, CS and IP, clears IF and TF and loads CS:IP from the vector table entry at vector x 4. The displays then show the handler address: use ST, or GO with that address. An empty table entry shows Err.
    • 

  • F1 breakpoint: type an address, NEXT. GO stops just before that address (display brEA). NEXT with nothing typed clears it. The Registers card shows BRK while one is set.
    • 

  • F2 dump: type an address (or only NEXT for the current IP). The status line shows 16 bytes and the Memory card follows; NEXT and PRV move by 16 bytes.
    • 

  • F3 hook: type an INT number, NEXT, then the handler address, NEXT. This fills the vector table entry so INT n (or VCT) calls your routine. NEXT with no address removes the hook.
    • 



Run a program (GO)
    

  1. Press 2 (GO).
    2. 

  2. Type the start address (any number of digits), then NEXT. NEXT does nothing until an address is typed.
    3. 

  3. Press TTY to run. TTY before NEXT does nothing.
    4. 

The program stops at CC (INT 3) or HLT. RESET stops it at any time and resets the registers. CS is 0000, so the address you type is the physical address.


Single step (ST)
    

  1. Choose the start: REG, C (IP), type the address, TTY. IP is 2000 after Power (RESET keeps the current value).
    2. 

  2. Press 3 (ST) to run one instruction. The displays show the next IP and its opcode.
    3. 

  3. Press ST again to continue and watch the Registers card change.
    4. 



Registers (REG / ER)
    

  1. Press REG (or 1 = ER at the idle screen).
    2. 

  2. Press the register key: 0 AX, 1 BX, 2 CX, 3 DX, 4 SP, 5 BP, 6 SI, 7 DI, 8 CS, 9 DS, A SS, B ES, C IP, D FL.
    3. 

  3. The address display shows the register name (A, B, C, D = AX, BX, CX, DX) and the data display shows its value. Type up to 4 hex digits to change it.
    4. 

  4. NEXT stores and shows the next register, PRV the previous one, TTY stores and exits.
    5. 



Keys and displays
    

  • Blue keys: RESET, REG, NEXT (CRT), PRV (FILL at idle), TTY (.), B.S, INS, DEL, VCT (INTR) and F1-F3.
  • Power button (red, next to 5 MHz): clears all memory and registers (in Training Mode it also returns to the main screen to pick a level). RESET only restarts the monitor; memory, registers and flags are kept.
    • 

  • Black keys: hex digits 0-F. At idle they run EB, ER, GO, ST, IB, OB, MV, EW, IW, OW, BC and VR. (LS and PRG require physical external hardware, so they are disabled).
    • 

  • Dot between the displays: lights while an address or a register is being shown or edited.
    • 

  • LEDs D7-D0 (Assembly editor screen): the last byte written by an OUT instruction.
    • 

  • PC keyboard: 0-9 and A-F, Enter = NEXT, Backspace = B.S, - = PRV, . = TTY, G = GO, Esc = RESET, Ins or + = INS, Del = DEL, V = VCT, F1-F3.
    • 



Assembly editor
    

  1. Write 8086 code in the editor. Use ORG to choose the load address (the sample uses ORG 2000h). Sample loads an example.
    2. 

  2. Assemble translates it and loads the bytes into RAM. Then run it with GO on the kit.
    3. 

  3. Assemble & Run does both at once (Ctrl+Enter also works). End your code with INT 3 so it stops.
    4. 

  4. Mistakes are listed with their line number in the listing below the editor.
    5. 



Troubleshooting
    

  • A key isn't working? Always check the green status screen! It tells you exactly what mode you are in and what to press next.
    • 

  • A black key types a digit instead of a command: the kit is not idle. Press RESET.
    • 

  • TTY does not run my program: after GO you must type the start address first, then press TTY.
    • 

  • The program never stops: end your code with CC (INT 3), or press RESET.
